## SM: STARTUP MEMORIAL

SM is a web application that archives failed startups and turns them into structured case studies.
The goal is to learn from what didn’t work by analyzing failure patterns, decisions, and proposed alternatives. It focus on what went wrong, why it happened, and how it could have been done differently.

### Features
- Browse an archive of failed startups across industries
- View detailed post-mortem analyses for each startup
- Submit alternative solutions and pivot ideas
- Like and dislike solutions and replies
- Threaded discussions under each solution
- AI-generated failure analysis and solution evaluation
- Real-time updates using Firebase Firestore

### Tech Stack

- React
- TypeScript
- Firebase Firestore (real-time database)
- Firebase Hosting
- Tailwind CSS
- Google Gemini AI
